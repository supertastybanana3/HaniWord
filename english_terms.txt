# 2026-10-29 C (まとめ役の依頼。git がどの表にも無く、gitttesugoi (git って すごい) が ぎ + っ + って になっていた): 文脈用の表にしか無いか、どの表にも無い、開発でよく打つ短い語。
# 3 字の語は語の切れ目でだけ英語を先にする扱い (ram = らむ と同じ)。git はこの形で git って・git しました・git とか が英字になり、ぎ で始まる日本語 (ギター gita-・gittai・ぎっちり・麦茶 mugitya) は崩れない

# (struct・const・impl・func・bool・int・diff・cors・toml・rst・tsc は structure・constant・boolean などを、sso・sass・uint は 日本語 (hasso など) を、
# scp・lsp は winscp・mailspring を崩すので入れない。enum は uenuma = 上沼 に出てくる。repo・sudo・todo・emoji・ide などの読める語は日本語の語と重なるので入れない)
