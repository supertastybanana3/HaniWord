# ラテン文字のつづりの指摘・自動修正の測り (tools/latin_spell)

IME 本体の `crates/client/src/engine/latin_spell.rs` (設定 `input.latin_spell`) の判断を、文の組で測る道具です。
判断のコードは IME と同じファイルを読み込みます (`#[path]`)。IME につなぐ部分 (`mod ime`) は Windows だけなので、この道具は Linux でも動きます。

## 使い方

```
cargo build --release
latin_spell_eval --tables <next_*.hwn のフォルダ> --words <リポジトリの頭 (english_names.txt などのある所)> --data <言語.txt のフォルダ> \
    --langs en,es,fr,de,it,pt,pl,cs,tr,da,sv,nb,is,fi --split dev|test [--limit N] [--show N] [--th 名前=値 ...]
```

- 表は配っている次の語の候補の表 (`next_<言語>.hwn`、`tools/next_words` で作るもの)。言語ごとに、IME で同じ言語を選んだときと同じ表 (英語＋その言語。
  北欧の言語は 5 つまとめて) を引く
- 直さない語は、IME と同じ `english_names.txt`・`english_brands.txt`・`english_case.txt` の英字だけの行
- 文の組は `<言語>.txt` (1 行 1 文)。行の番号が偶数の文を dev、奇数の文を test にする
- `--th` は線 (`latin_spell::Thresholds` の名前) を変えて試すため

## 数えるもの

文は Space で区切った塊ごとに、それより前の文を前の文脈にして確かめる (IME が Space で確定するときと同じ)。

- 正しい文: 変えた語の数 (指摘・自動修正)
- 1 字違い: 1 文に 1 か所、機械で 1 字違い (隣のキーの置き換え・抜け・余り・入れ替え) を入れ、直った・違う形に直した・直さなかった。
  入れた綴りがどれかの表にある語になったもの (form と from のような語の取り違え) は数えない (この判断は直さないので)
- アクセント: アクセントのある語を 1 つ選んでアクセントを外し、同じように数える。外すと表にある語になるもの (está → esta) は、
  その語だけでは決まらないので、ここでは直さない (数には入る)
- 前の語のアクセント (Tu hablas → Tú hablas。指摘だけ): 外すと表にある語になる組は、すぐ後ろの語とのつながりで、打っている語の候補に
  前の語の直しを出す。正しい文では、後ろの語を 1 字ずつ打つ間に一度でも前の語の指摘が出たら「誤った指摘」。
  アクセントを外した文では、後ろの語を打ち終えたときに元の形の指摘が出たら「戻った」

## 文の組 (配らない。測りにだけ使う)

Tatoeba (https://tatoeba.org、CC BY 2.0 FR。一部 CC0) の言語ごとの例文のうち、次の語の候補の表を作るときに試験用に分けた 5%
(記事 ID を 20 で割って 0 の文から、学習用と同じ文・1 語違いの文を除いたもの。`tools/next_words/tatoeba_split2.py`)。
表を作るのに使っていない文なので、測りが表に引きずられない。

## 線を決めた結果 (2026-11-05)

dev (各言語 1,000 文、14 言語で 1.1 万文) で、指摘の差・自動修正の差・表に無い語の点の組み合わせ 13 通りを比べ、
指摘は正しい文を変える数が 0.05% 前後、自動修正は正しい文を変える数と違う形に直す数がほぼ 0 になる線を選んだ
(`Thresholds::default()`)。test (各言語の奇数行すべて、14 言語で 96,884 文・774,034 語) で確かめた結果:

| | 正しい文を変えた | 1 字違い (86,685) が直った | 違う形に直した | アクセント (14 言語) が戻った |
|---|---|---|---|---|
| 指摘 | 274 語 (0.035%) | 51.8% | 984 (1.1%) | 11.2% |
| 自動修正 | 32 語 (0.004%) | 15.3% | 62 (0.07%) | 6.3% |

英語だけでは、指摘 28 語 (0.010%)・直った 58.5%、自動修正 9 語 (0.003%)・直った 17.0%。
正しい文を変えた語には、試験の文そのものの打ち間違いを直したもの (irgenwie → irgendwie) も入っている。
多いのは語尾の長く連なる言語 (トルコ語の指摘 0.17%) で、表に無い正しい活用形が多いため。

前の語のアクセント (`previous_accent_margin`): dev (13 言語 6.9 万組) で 2300〜13800 を比べた。11500 以上だと
Tu hablas → Tú hablas (表の点の差 9341) が出ないので 9200 にした。test (14 言語 677,150 組) で、誤った指摘 113 (0.017%)、
外すと表にある語 39,287 のうち戻った 9,052 (23.0%)・違う形 51。残る誤った指摘は el vino (ワイン)・él vino (来た) のように後ろの語だけでは決まらない組。

1 語に 2 つ以上のアクセント (élève・informação・příliš) は、アクセントを外した形で表を引いて、いくつ外した語でも 1 回で戻す
(前は 1 字ずつの置き換えだけで、2 つ以上を外した語は戻らなかった)。戻す先は表にある語だけなので、一部だけのアクセントの形 (elève) は
表にあるときしか出ない。test でアクセントの数ごと (外した語・全部戻った・大文字小文字だけ違う・一部だけ・違う語):
1 つ 35,123・4,570 (13.0%)・38・0・87、2 つ 4,172・1,065 (25.5%)・6・2・4、3 つ以上 1,568・359 (22.9%)・4・0・1。
大文字小文字だけ違うのは、表の書く形がよく使うほう (lügen を Lügen) のため。アクセントの戻りは全体で 指摘 14.7%・自動修正 8.4% になった。

2026-11-05 (まとめ役の決め): アクセントの違いだけの表にある語が 2 つ以上 (elève・élève、élève・élevé) なら、打っている語のアクセントの直しは出さない
(前の語の指摘は前後の語で決めるので別)。アクセントを付けるときは字の大きさを打ったとおりにする (lugen → lügen)。
test で、1 つ 35,123・4,482 (12.8%)・0・0・91、2 つ 4,172・997 (23.9%)・0・0・6、3 つ以上 1,568・358 (22.8%)・0・0・0
(外した語・全部戻った・大文字小文字だけ違う・一部だけ・違う語)。アクセントの戻りは 指摘 14.3%・自動修正 8.2%、
前の語のアクセントは 25.0%・違う形 14・誤った指摘 0.017%。

## ドイツ語の名詞の頭の大文字 (2026-11-05)

ドイツ語を選んだ人が、文の途中の名詞を小文字で打った所 (haus・zum leben) を大文字にする (指摘と自動修正)。アクセントを付ける直しと組み合わさるときは、
アクセント → 大文字 の順 (lugen → lügen → die Lügen)。文の頭の語は見ない。
次の語の候補の表は語を小文字にそろえて数えているので、名詞か動詞かは表から分からない。そこで `german_case.tsv` (IME 本体の隣) を別に作った:

1. `python3 -I german_case/count_case.py <FineWeb-2 のドイツ語の文 (次の語の候補の表の元)> <読むバイト数> <出力のフォルダ>`
   (文の途中の語の、大文字で始まった割合と、前の語のあとの割合・前の語と語の組の割合を数える。2026-11-05 は先頭の 4 億バイト)
2. `python3 -I german_case/make_table.py <出力のフォルダ> latin_words/de.txt german_case.tsv` (語 25,996・組 19,034・前の語 2,541、930KB)

見込み: 前の語と語の組が表にあれば組の割合 (語の割合でならす)、無ければ語の割合と前の語の割合を掛け合わせる (zum leben 97%・wir leben 3%)。
線は dev のドイツ語 (12,872 文) で 900〜990 を比べ、正しい文の小文字の語を大文字にした数が ほぼ 0 の 指摘 980・自動修正 990 にした。
test のドイツ語 (12,872 文・116,040 語) で、正しい文の小文字の語を大文字にした 指摘 3・自動修正 1、文の途中の名詞を 1 つ小文字にした 10,139 文で
直った 指摘 58.7%・自動修正 37.5%・違う形 0。
