# 固有名詞の表 (extra_dictionaries/core_names.tsv)

よく知られた人・グループ・作品・団体・出来事・地名と、日本の上場企業の名前を、オフにできない追加辞書として足す表です (仕事 44、2026-11-07)。
azooKey の辞書に同じ表記と読みがある名前 (米津玄師・大谷翔平 など) は足しません。

## 材料

- 日本語版ウィキペディアの全文 (Hugging Face の wikimedia/wikipedia 20231101.ja。2023-11-01 のダンプで、元は CC BY-SA 3.0 / GFDL) の parquet と、文に分けたもの (記事の番号<TAB>文)
- Wikidata (CC0) の MediaWiki の API (`www.wikidata.org/w/api.php`。`query.wikidata.org/sparql` は robots.txt が断るので使わない)
- Wikimedia Analytics API の閲覧数 (CC0。pageviews/top) と、月ごとの閲覧数のダンプ (dumps.wikimedia.org の pageview_complete の月の集計、CC0。
  1 か月 5.5GB ほど。User-Agent の決まりを守り、1 つの IP から 3 つまでの接続の決まりの中で 1 つずつ取る)
- 日本語版ウィキペディアの MediaWiki の API (カテゴリ)
- azooKey の辞書 (tools/extra_dict/dump_azookey_dict.py の出力) と、ほかの追加辞書 (core_*.tsv)

どの API も、連絡先つきの名乗り・1 つずつ・間をあける・429 と maxlag なら待つ、で使います (wd_api.py・fetch_*.py)。

## 手順

1. 上場企業: `fetch_companies.py companies.jsonl` (東京・名古屋・札幌・福岡の証券取引所を上場先 P414 に持つ項目を haswbstatement で探し、wbgetentities で
   日本語のラベル・日本語版の記事名・銘柄コード P249・上場の終わり P582・解散 P576 を取る)。記事があり・上場中・銘柄コードつき・解散していない会社の記事名の表を作る
2. 閲覧数の上位の記事: `fetch_top.py top_monthly.jsonl` (月ごとの上位 1,000、2015-07〜) → `filter_top.py` (道具的な記事・一覧・年や日付を外す) →
   `fetch_categories.py` (カテゴリ) → `classify_ab.py` (カテゴリで 人物・作品・グループ・団体・出来事・地名と施設 と、ふつうの語・決まらない に分ける)
3. 書き出しの読み通し: `extract_names.py persons.tsv <parquet ...> --titles <会社と上位の記事の記事名> --companies-out titled.tsv`
   (人物の記事の「名前（よみ、年…）は、」と、指定した記事の書き出しの「名前（括弧）は、」を 1 回の読み通しで拾う)
4. 数え: 人と会社の名前を全文で数え (`grep -oF -f names.txt`、名前は `company_names.py` と persons.tsv から)、`rank.py` で辞書にある名前を外して並べる。
   `name_boundary.py` で、名前ごとに 1 つの束で 30 文まで抜き、名前の頭と終わりが語の切れ目 (Sudachi の A 単位) にそろう割合を出す (テイン が プロテイン に当たるような数を除く)
5. `company_table.py` (会社の表記・読み・数。読みは書き出しの括弧の頭のかなで、株式会社 などを除いた登記の名前に付ける。かなだけの社名は表記のかな)
6. `a_candidates.py` (候補を 1 つの表に。全文の目安の数 = 全文の数 × 切れ目の割合。人でない記事 (法令・施設・競走馬など) と、
   表記がふつうの語と同じもの・1 字のものに印) → `a_line.py` (線の案と境目)
7. 競走馬: `extract_horses.py` (書き出しの説明に 競走馬・種牡馬・繁殖牝馬 がある記事) → 名前を全文で数え、`name_boundary.py` で切れ目の割合。
   (GI の数えの試し問題: `fetch_wikitext.py` で記事の wikitext を取り、`parse_records.py` で戦績の表から GI・JpnI の出走と勝ち、`classify_names.py` で重なりの型)
8. 月の閲覧数: `PVC_DIR=<置き場> MONTHS="202610 202607 202604 202601" fetch_pageview_dumps.sh` (月の集計を取りながら展開し、ja.wikipedia の行を記事ごとに足す。
   ファイルは残さない) → `pv_line.py a_candidates.tsv <置き場>/months <names_types.tsv> a_pv.tsv` (候補ごとの月の平均。同じ表記と読みの行は記事の合計)
9. `make_names_table.py a_candidates.tsv <流行語大賞の受賞語の区分> <azookey_dict.tsv> core_names.tsv excluded.tsv <core_*.tsv ...> --pv a_pv.tsv --pv-min 300 [--drop culprits.tsv]`
10. 確かめ: 一般の文と分野の文を表なし・表ありで変換し、`names_culprits.py core_names.tsv culprits.tsv <前.jsonl> <後.jsonl> ...` で、
    正しかった所を替えた名前 (崩れた・所が崩れた) を拾う → 9. に `--drop drop_measured.tsv` を付けて作り直し、数え直す
    (drop_measured.tsv は 2026-11-08 の 3b で拾った 26 語・出力に出ない形で確かめた 音通・数え直しで拾った 井上博)

## 決まり (2026-11-07、どの分野の名前にも同じ物差しを当てる)

- 線: 月ごとの閲覧数のダンプの 4 か月 (2026-01・04・07・10) の月の平均が 300 以上。同じ表記と読みの名前 (同じ名前の別の人) は、その記事の閲覧数の合計で見る
- 上場企業は線によらず、読みの取れた会社を全部
- 名前でない記事の題 (〜法・〜令・〜規則・〜条約・〜条例・一覧・年や日付)、記号を含む題、表記がふつうの語と同じもの、1 字のものは入れない。
  記号は、残す記号 (・ ー 々 と、半角・全角の - . & ' /。名前の中で実際に使う形) 以外の記号・句読点 (、。！？・括弧・☆★♪→〜 など) を含めば入れない (2026-11-08 に一覧を広げた)
- 表記に会社・法人の形の語 (株式会社・一般社団法人 など) があって読みにその読みが無ければ、表記からその語を外す (株式会社新潮社 → 新潮社。2026-11-08)
- かな・漢字と英字の混じる表記で、英字を除いた部分だけで読みどおりに作れるもの (将軍SHŌGUN の読み ショウグン) は入れない (2026-11-08)
- 確かめの測りで正しかった所を替えた名前 (同じ読みの別の人・ふつうの言い方と同じ読み: 鈴木大介 → 鈴木大輔、長野行き → 長野佑紀) は入れない (2026-11-08)。
  名前が出力に出ないまま AI の選び方を変えることもある (上場企業の 音通 (おんつう) が 温痛覚 と読みが重なり、医学の文の 他の が ほかの になった)。
  names_culprits.py は出力に出た名前しか拾えないので、崩れた文に表の語が出ていなければ、文の読みの中に読みが重なる表の語を探し、
  表をその 1 行だけにした置き場と、その行を外した置き場で同じ文を流して確かめる。確かめた名前は drop_measured.tsv に例と一緒に足し、--drop で外す
- 読みが 2 字までの名前は入れない (KANA・里歩 など。ふつうの語の並びの切れ目と読みが重なり、出力に名前が出なくても AI の選び方を変える。2026-11-08)
- 名前でない題 (千円紙幣 など) を「地名と施設」から分けるのは、すべての記事の題を 1 つの決まりで分ける仕事 46 で行う (2026-11-08 の決め)
  azooKey の辞書か追加辞書に同じ表記と読みがあれば足さない
- 人・グループ・作品・団体・出来事・地名・競走馬・その他の固有名詞を同じ山に入れ、分野ごとの決まりは作らない
- 品詞の番号: 人・グループ・競走馬 1289、作品・出来事・その他の固有名詞 1288、会社・団体 1292、地名と施設 1293 (azooKey の辞書の 米津玄師・乃木坂46・鬼滅の刃・トヨタ自動車・東京スカイツリー にならう)
- 値: 読みが 5 字以上は -13.0、4 字までは -14.5。同じ読みの語が辞書にあれば、そのいちばん高い値より 0.5 下 (ふつうの語より上に出ない)

## 確かめ方

一般の文 (wiki_luna_full、3,675 文) と 13 分野の文の組を、表を入れた形と入れない形で変換し (AI あり・辞書だけ)、正しかった 1 番目が替わった数 0 を確かめる。
替わった文があれば、原因の名前を外して数え直す。
