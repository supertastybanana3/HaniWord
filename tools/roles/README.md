# 役割語の表 (extra_dictionaries/core_roles.tsv)

物語の中の人物の言葉 (役割語) の一人称・二人称と語尾を、オフにできない追加辞書として足す表です (仕事 39、2026-11-07)。
おいどん・わらわ・拙者・吾輩・あちき・わっち・わて などの一人称・二人称と、ござります・ざます・ありんす・だっちゃ・でやんす などの語尾を、
ふつうの語の変換を変えない値で入れます。

## 材料

`roles_src.tsv`: 日本語版ウィキペディアの次の記事 (CC BY-SA 4.0、2026-11-06 に MediaWiki の API で取った版) に書いてある役割語の語と読み・種類・役割。
開いた記事に書いてあるものだけを入れました (表記・読み・種類・役割・出典の記事・記事の中の場所)。
「役割語」(110771186)・「お嬢様言葉」(111459006)・「山の手言葉」(109748002)・「廓詞」(109594682)・「老人語」(111596552)・
「日本語の一人称代名詞」(111657016)・「日本語の二人称代名詞」(111212736)

## 作り方

`python3 -I make_roles_dict.py roles_src.tsv <azookey_dict.tsv> ../../extra_dictionaries/core_roles.tsv`
(azookey_dict.tsv は tools/extra_dict/dump_azookey_dict.py で書き出す azooKey の辞書)

- 一人称・二人称は代名詞 (1306。わし・わたくし・吾輩・拙者 と同じ位置)。語尾は同じ位置に付く標準語の語を手本に (です 460・ます 491・だろう 455・くれ 940・遊ばせ 625)。
  です・ます・わ・よ・の の組み合わせで出る語尾 (ですわ・てよ・あるよ・なのだ・じゃ) は足さない
- 値: -9.0 と、読みのぶつかる普通の語より 0.5 下の、低いほう (わし = 鷲 のように、読みが普通の語とぶつかる語は 1 番目を取らない)
- うち (西日本の女性の一人称) は、内・家 の意味が多い語なので入れない。ミー は、AI ありの変換で みーはいく を ミーハイク にしたので入れない

## 確かめ

- 一般の文 (wiki_luna_full、3,675 文): 表を入れても AI あり 2,479 → 2,479・辞書だけ 1,313 → 1,313 (変わった文 0、2026-11-07、うち と ミー を入れた形で測った)
- 人称の語の 〜はいく・〜がいった (27 語・54 文): 〜は行く・〜が言った が残る文は表を入れても AI あり 50 → 50・辞書だけ 53 → 53 (悪くなった文 0)
