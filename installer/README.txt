HaniWord 0.1.0

Windows 用の日本語入力 (IME) です。azooKey-Windows (fkunn1326 氏、MIT License) をもとにしています。
不具合や質問は GitHub の Issues へお願いします: https://github.com/supertastybanana3/HaniWord/issues
(元の azooKey-Windows や azooKey の開発者には問い合わせないでください)

■ 使い方
・Win + Space で「HaniWord」を選び、半角/全角 キー (US 配列なら Alt + `) で「あ」にして打ちます
・入力しながら自動で変換されます (ライブ変換)。Enter で確定します
・Space で候補の一覧を出します。←→ で文節を移り、Shift + ←→ で文節を伸び縮みさせます
・Esc を 1 回押すと読み (ひらがな) に戻り、もう 1 回押すと打った分を消します
・英字になった所を かな にしたいときは、無変換キー (または F6 でひらがな、F7 でカタカナ) で戻せます (ローマ字として読める綴りのときだけ)
・F6〜F10 で、ひらがな・カタカナ・英字に変えます
・確定した変換は覚えていきます。学習データは %APPDATA%\HaniWord\memory に置き、この PC の外には送りません
  (HaniWord は、打った文字を PC の外に送りません。通信するのは、インストール中に変換のモデルを取得するときと、
   1 日 1 回 GitHub で新しい版が出ていないかを確かめるときの 2 つだけです。どちらも、打った文字・学習・設定は送りません。
   版の確かめは、設定の「全般」→「バージョンと更新プログラム」→「新しい版を知らせる」で切れます。
   候補の一部に Windows の仕組み (Windows.Data.Text) を使っています)
・設定は、スタートメニューの「HaniWord の設定」か、タスクバーの「あ」を右クリックして「設定を開く」で、いつでも変えられます

■ おもな機能 (どれも設定で切り替えられます)
・AI による変換: ニューラルかな漢字変換のモデル (zenz) が、前後の文脈を読んで同じ読みの語から合うものを選びます。
  AI は PC の中で動きます。Ctrl + 変換 で辞書だけの変換に切り替えられます
・重いときは AI をオフに: ほかのアプリの負荷などで AI の変換がふだんよりずっと遅くなったら、自動で辞書だけの変換にし、
  速さが戻ったら AI に戻します。オフの間は候補の窓の下に「負荷がかかっているためAIがオフになっています」と出ます
  (初期値はオフで、設定でオンにできます)
・英語と日本語の自動の打ち分け: google・windows のような英単語は、ローマ字にせず英字のまま入れます。
  github・pdf は GitHub・PDF のような決まった表記に直します
・大文字で始まる語は、その語だけ英字のまま (Googledekensaku → Googleで検索)。
  設定で、大文字を打ったら確定まで英字にもできます (NHKnonyu-su → NHKのニュース)
・次の語の候補: 英単語を打っている途中に、前の語から続きそうな語を出します。Tab で補います。
  英数 (A) のときも、カーソルの近くに出します (端末・コードエディタ・パスワード欄では出しません)
  (初期値はオフで、設定の「全般」→「英単語の候補」でオンにできます)
・アクセント付きの文字: 選んだ言語 (フランス語・ドイツ語・スペイン語など 13 言語) のキーを長押しすると é ñ ü などを選べます。
  その言語の単語は日本語と見分けて英字のまま入れ、次の語の候補も出します。
  言語は設定アプリの「外国語の入力」で選びます (インストールのときに選ばなければ英語だけ)。
  インストールのあとで設定アプリから選んだ言語は、長押しはすぐ使えますが、その言語の次の語の候補・つづりの直しの表は入っていません。
  表は、インストーラーをもう一度実行すると入ります (設定で選んである言語の表を入れます)
・記号の全角・半角: 全部全角・全部半角・！？～だけ全角、または記号ごとに選べます。¥ キーで入る字 (¥ か \) も選べます (「ろ」キーはいつも \)
・数式・化学式の入力: x^2 → x²、H_2O → H₂O、H2O → H₂O、アルファ → α、2.0 や 1,000 の小数点・桁区切り
・zh zj zk zl で ← ↓ ↑ →
・端末で PowerShell・コマンド プロンプト・bash が入力を待っているときは英字のまま入れます
・行頭や空白の後に / $ @ を打つと、続く語を変換せずにアプリへ渡します
・確定後の Shift + Space は、ふだんの Space と逆の幅 (全角／半角) の空白を入れます
・Ctrl + 変換 で辞書だけの変換と AI の変換を切り替えます。Ctrl + 無変換 で H₂O・α のような自動の表記を、打ったとおりに戻します
・Ctrl + Shift + 変換 で、選んだ漢字の異体字 (登録済みのもの) を切り替えます (表示はフォントとアプリによります)

■ キーの一覧 (変換・無変換 キーの無い US 配列などでは、右のキーで同じことができます。JIS 配列でも使えます)
・あ／A の切り替え ............ 半角/全角 → Alt + ` (1 の左のキー。設定で Ctrl + Space も選べます。初期値オフ)
・AI の変換 ↔ 辞書だけの変換 ... Ctrl + 変換 → Ctrl + J
・表記の切り替え H₂O ↔ H2O .... Ctrl + 無変換 → Ctrl + B
・異体字を回す ................ Ctrl + Shift + 変換 → Ctrl + Shift + J
  Ctrl + J・Ctrl + B は、入力中・変換中で読みがあるときだけ受け、ほかのときはアプリへそのまま渡します。
  Alt + ` はキーの位置 (1 の左のキー) で決めるので、JIS 配列の Alt + @ はアプリへ渡します。
  キーを割り当て直す道具で、IME オン (VK_IME_ON) は「あ」、IME オフ (VK_IME_OFF) は「A」になります

■ インストールのとき
・変換の AI モデル (zenz-v3.2-small、Miwa-Keita 氏、約 74MB) は、インストール中に Hugging Face の作者の公開場所から取得し、
  SHA-256 で中身を確かめてから入れます。インターネットにつながった状態でインストールしてください。
  モデルのライセンスは、取る版 (c67e03e) のモデルカードでは Apache-2.0、今のモデルカードでは CC BY-SA 4.0 と表示されています。
  HaniWord は、厳しいほうの CC BY-SA 4.0 として扱います (HaniWord には同梱していません)
    取る版のモデルカード: https://huggingface.co/Miwa-Keita/zenz-v3.2-small-gguf/blob/c67e03e07d215c869f591b274c1631170d3e11fe/README.md
    今のモデルカード: https://huggingface.co/Miwa-Keita/zenz-v3.2-small-gguf/blob/main/README.md
・「おすすめの設定ですぐに使う」を選ぶと、設定のページを飛ばして初期設定のまま入れます。設定はあとから変えられます
・専門分野のページは、どちらを選んでも出ます。よく打つ分野 (法律・医学・数学など 11 分野) にチェックを入れると、
  その分野の話でない文でも用語が出やすくなります。選ばずに次へ進んでもかまいません (あとから設定アプリで変えられます)
・更新のときは HaniWord の変換サーバーと候補窓だけを止めます。メモ帳などのアプリは閉じません。入力途中の文章は先に確定してください
・前の版の設定と学習データは上書きしません。更新したあとは、使っているアプリを開き直してください

■ 動かないとき・制限
・Win + Space で Microsoft IME などに戻せば、元どおりに入力できます
・最初の変換だけ、GPU の準備で数秒かかります
・US 配列 (英語キーボード) を使うときは、Windows の言語の設定で、日本語の「ハードウェア キーボード レイアウト」を
  「英語キーボード (101/102 キー)」に変えてください (変えたあとは再起動が要ります。HaniWord はこの設定を変えません)。
  インストールのときに日本語を新しく足したとき (英語版の Windows など) は、インストーラーが同じことを案内します。
  あ／A の切り替えと 変換・無変換 の代わりのキーは「キーの一覧」のとおりです
・GPU (Vulkan) があると速く変換できます。GPU で動かないときは CPU に切り替えますが、遅くなります
・このソフトには署名がありません。「スマート アプリ コントロール」がオンの PC ではブロックされます。
  利用のために Windows の保護機能を無効にしないでください
・ユーザー アカウント制御 (UAC) をオフにした PC と、組み込みの Administrator アカウントでは、インストールできません
  (変換サーバーなどを、管理者ではないふだんの権限であなたのフォルダへ写すため)。
  管理者ではないアカウントに、別の管理者のパスワードを入れてインストールすることもできません
・不具合を調べるための診断ログは、%APPDATA%\HaniWord\debug_log_path.txt (書き出すファイルのパスを書いたもの) を置いたときだけ書きます
  (ふだんは書きません)。有効にすると、打った文字と窓の題がそのファイルに残ります。書き出すファイルは %APPDATA%\HaniWord の中だけに置けます。
  人に渡す前に中身を確かめ、要らなくなったら debug_log_path.txt とログのファイルを消してください
・開発中のソフトです。安全性や不具合のないことを保証するものではありません

■ アンインストール
・設定 → アプリ → インストールされているアプリ →「HaniWord」
・アンインストールしても、あなたのフォルダ (%APPDATA%\HaniWord) の学習データ・設定・変換サーバー・モデルは残ります
  (管理者権限で動くアンインストーラーに、あなたのフォルダの中を消させないため)。
  学習を消したときの控え (memory_backup_<日時> のフォルダ。設定で学習を消す前に写したもの) と、
  壊れていた学習のファイル (memory_corrupt_<日時> のフォルダ。停電などで切れた学習を読めなかったときに退けたもの) も、このフォルダの中に残ります。
  要らなければ、アンインストールのあとでエクスプローラーから %APPDATA%\HaniWord フォルダを消してください (元に戻せません)。
  単語登録の「書き出す」で書いたファイル (ドキュメントのフォルダ) など、自分で別の場所に保存したものは別に消してください
